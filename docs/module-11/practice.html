D1 · Explore a relationship

Pattern: two numeric columns on x and y; one categorical column mapped to color (and shape); a fixed alpha when points overlap.

Predict

Bill length and bill depth: when one goes up, does the other go up or down? Will the answer change once each species gets its own color? Write your prediction before running anything.

TipShow answer

Look at the two plots below. Without color, the whole cloud tends to go down: longer bills look shallower. With color, within each species the points go up. The overall trend mixes three groups that sit in different places. Mapping the group to color reveals it.

Run

ggplot(penguins, aes(x = bill_length_mm, y = bill_depth_mm)) +
  geom_point()
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).
ggplot(penguins, aes(x = bill_length_mm, y = bill_depth_mm,
                     color = species, shape = species)) +
  geom_point()
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).

Investigate

  1. What does one point stand for? What does the warning in the console say, and why?
  2. Why map species to both color and shape?
  3. You will set alpha = 0.4 below. Why is alpha set (outside aes()) and not mapped?
TipShow answers
  1. One penguin. Rows with a missing bill length or depth have no position, so geom_point() removes them and says so in the warning.
  2. Two cues for the same column: the plot still reads in grayscale and for readers who do not see color differences (color is never the only cue).
  3. Transparency here is not information about each penguin; it is one design choice for all points so overlaps show. One value for every mark is a setting.

D2 · Amount per group

Pattern: make a small table with one row per group (count() or summarise()), then draw it with geom_col().

Predict

penguins %>% count(island) makes a table. How many rows will it have, and how many columns will the plot below have?

TipShow answer

Three rows (Biscoe, Dream, Torgersen), so three columns: one mark per row.

Run

island_counts <- penguins %>% count(island)
island_counts
# A tibble: 3 × 2
  island        n
  <chr>     <int>
1 Biscoe      168
2 Dream       124
3 Torgersen    52
ggplot(island_counts, aes(x = island, y = n)) +
  geom_col()

Investigate

  1. True or false: geom_col() counts the rows for you.
  2. Run penguins %>% count(sex). Why are there three rows? What will the plot show for the third one?
  3. geom_col() draws any number you computed, not only counts. Which function from Module 5 makes a table of means per group?
TipShow answers
  1. False. count() did the counting; geom_col() draws the heights you give it. (geom_bar() counts for you because it computes a statistic: Module 12.)
  2. The third row is NA: penguins whose sex was not recorded. The plot shows a column labeled NA. Missing values are data too.
  3. group_by() + summarise().

Modify

Draw the number of penguins measured in each year.

ggplot(year_counts, aes(x = year, y = ___)) +
  geom_col()
TipShow solution

ggplot(year_counts, aes(x = year, y = n)) +
  geom_col()

Make (choose one)

  • Option A (Sexes): count penguins by sex and draw the counts.
  • Option B (Means, not counts): mean body_mass_g per species with group_by() + summarise(), drawn with geom_col().

D3 · Change across time

Pattern: summarise() one number per group and time point, then draw one line per group with geom_line().

Predict

penguin_means below has one row per species and year. Will the first plot show one line or three?

TipShow answer

One line that zigzags: nothing tells ggplot2 the rows belong to three species, so it joins all points in order of x and jumps up and down at each year.

Run

penguin_means <- penguins %>%
  group_by(species, year) %>%
  summarise(mean_mass = mean(body_mass_g, na.rm = TRUE),
            .groups = "drop")
penguin_means
# A tibble: 9 × 3
  species    year mean_mass
  <chr>     <dbl>     <dbl>
1 Adelie     2007     3696.
2 Adelie     2008     3742 
3 Adelie     2009     3665.
4 Chinstrap  2007     3694.
5 Chinstrap  2008     3800 
6 Chinstrap  2009     3725 
7 Gentoo     2007     5071.
8 Gentoo     2008     5020.
9 Gentoo     2009     5141.
ggplot(penguin_means, aes(x = year, y = mean_mass)) +
  geom_line()

Investigate

  1. How many rows does penguin_means have? Why that number?
  2. Run both plots below. Which geom follows the order of the rows, and which sorts by x first?
walk <- tibble(step = c(1, 3, 2), place = c(10, 30, 15))
ggplot(walk, aes(x = step, y = place)) + geom_line()
ggplot(walk, aes(x = step, y = place)) + geom_path()
  1. The x axis shows values like 2007.5. Is that a problem with the data or with the axis?
TipShow answers
  1. Nine: 3 species × 3 years, one row per combination.
  2. geom_path() follows the row order (1, 3, 2); geom_line() sorts by x (1, 2, 3). Minard’s map is a path: the army’s route, in order.
  3. The axis: ggplot2 chose breaks for a continuous number. Changing breaks is part of scales (Module 13).

Modify

Give each species its own line.

ggplot(penguin_means, aes(x = year, y = mean_mass, color = ___)) +
  geom_line()
TipShow solution 
ggplot(penguin_means, aes(x = year, y = mean_mass, color = species)) +
  geom_line()

A discrete mapping (color) also makes groups, so there is one line per species. group = species would do the grouping without color.

Make (choose one)

  • Option A (Flippers): mean flipper_length_mm per island and year, one line per island.
  • Option B (Counts over time): count(species, year), then one line per species showing how many penguins were measured each year.
TipShow solutions

  group_by(island, year) %>%
  summarise(mean_flipper = mean(flipper_length_mm, na.rm = TRUE),

ggplot(flipper_means, aes(x = year, y = mean_flipper, color = island)) +

species_year <- penguins %>% count(species, year)
ggplot(species_year, aes(x = year, y = n, color = species)) +
  geom_line()
ImportantPattern for Guided Project task B3 (and A3 for Credit Card)

If your data has a time or order column (season, year, game number, round; Credit Card: month), summarise() one number per group and time point, then geom_line() with the group mapped to color. Check the number of rows first: groups × time points.

D4 · A summary layer on the raw data

Pattern: layer 1 shows every row; layer 2 brings its own small table (one row per group) with its own aes(); layer 3 labels it.

Predict

species_centers has columns species, mean_flipper and mean_mass. The second layer below has no aes() of its own. Will it run?

TipShow answer

No. x and y are set in ggplot(), so every layer inherits them. The second layer looks for flipper_length_mm in species_centers, which does not have it.

Run

species_centers <- penguins %>%
  group_by(species) %>%
  summarise(
    mean_flipper = mean(flipper_length_mm, na.rm = TRUE),
    mean_mass = mean(body_mass_g, na.rm = TRUE)
  )
species_centers
# A tibble: 3 × 3
  species   mean_flipper mean_mass
  <chr>            <dbl>     <dbl>
1 Adelie            190.     3701.
2 Chinstrap         196.     3733.
3 Gentoo            217.     5076.
ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g)) +
  geom_point() +
  geom_point(data = species_centers, size = 5, shape = 4)
Error in `geom_point()`:
! Problem while computing aesthetics.
ℹ Error occurred in the 2nd layer.
Caused by error:
! object 'flipper_length_mm' not found

Investigate

  1. Read the error: which column is missing, and in which layer?
  2. Fix it by giving the second layer its own aes(x = …, y = …). Which columns go there?
  3. In the plot below, color = species is in ggplot(). Are the X marks colored? Why?
ggplot(penguins, aes(x = flipper_length_mm, y = body_mass_g,
                     color = species)) +
  geom_point() +
  geom_point(data = species_centers,
             aes(x = mean_flipper, y = mean_mass),
             size = 5, shape = 4)
Warning: Removed 2 rows containing missing values or values outside the scale range
(`geom_point()`).
TipShow answers
  1. flipper_length_mm, in the 2nd layer.
  2. aes(x = mean_flipper, y = mean_mass): the columns of species_centers.
  3. Yes. A mapping in ggplot() is global: every layer whose data has a species column uses it. Put color = species inside the first geom_point() to make it local to that layer.
